MarcViiew

A Wii homebrew library catalogue for organising, discovering, and exporting metadata about Wii software.

View repositoryExplore research
CURRENT MILESTONE0.6.0-beta

Feature-focused catalogue discovery is substantially implemented, with current development moving toward API refinement, validation, UI work, and testing.

WHAT IT DOES

A library catalogue built for software.

DISCOVERY

Find software across storage

MarcViiew can discover physical Wii software and compatible digital software across the Wii's storage environments.

  • WBFS software on SD and USB
  • NAND-installed titles
  • SD/USB digital-title discovery
  • Duplicate discovery merging
METADATA

Turn titles into records

Catalogue entries combine game metadata with Wii-specific source and distribution information.

  • GameTDB metadata
  • MARC 21 records
  • Source metadata such as SD, USB, or NAND
  • Physical versus digital distribution
MARC 21

Work with bibliographic records

The catalogue uses a project-specific MARC 21 profile for Wii software and supports viewing records directly on hardware.

  • MARC field display
  • Wii-specific cataloguing rules
  • Physical carrier treatment
  • Imported external MARC records
ISO 2709

Export the records

MarcViiew connects catalogue records to ISO 2709 encoding through ViiewLib.

  • ISO 2709 export
  • Record encoding experiments
  • Portable MARC data workflows
  • Hardware-tested workflows

CATALOGUING MODEL

Separating what software is from where it came from.

MarcViiew distinguishes distribution from source. A title can be physically distributed while currently stored on SD, or digitally distributed while installed on NAND. Keeping those concepts separate makes the catalogue more useful for preservation and collection management.
