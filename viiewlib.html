PROJECT · C LIBRARY · MARC 21 / ISO 2709

ViiewLib

A lightweight C library for reading, manipulating, validating, and encoding MARC 21 records and ISO 2709 data.

View repositorySee MarcViiew
ROLE IN THE ECOSYSTEMMarcViiew's record layer

ViiewLib provides the lower-level MARC and ISO 2709 functionality that lets MarcViiew work with structured bibliographic data.

PURPOSE

Small, focused tools for structured bibliographic data.

MARC 21

Record handling

ViiewLib provides C-side structures and operations for working with MARC records and their fields and subfields.

ISO 2709

Encoding and decoding

The library connects structured MARC data with ISO 2709's record-oriented interchange format.

VALIDATION

Safer record workflows

Validation and error handling are part of the longer-term refinement work, with the goal of making record operations predictable and easier to debug.

PORTABILITY

Designed for homebrew

The project is developed in C with Wii homebrew as its primary environment, while keeping the library's concepts focused enough to be useful beyond one application.

WHY A LIBRARY?

Keep the catalogue application separate from the record machinery.

MarcViiew needs to think about games, storage, discovery, catalogue interfaces, and Wii hardware. ViiewLib can instead concentrate on MARC 21 and ISO 2709. That separation makes the projects easier to test, document, and potentially reuse.

DEVELOPMENT

Future work.

01API refinement

Improve naming, consistency, documentation, and the public interface as real MarcViiew usage exposes edge cases.

02MARC validation

Expand validation and interoperability testing against MARC 21 and ISO 2709 expectations.

03Test coverage
