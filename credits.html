PROJECT COMPONENTS

Software and vocabularies developed within the project.

MARC & ISO 2709

ViiewLib

A lightweight C library developed for MARC 21 record handling and ISO 2709 encoding and decoding. ViiewLib provides core record and interchange functionality used by MarcViiew.

ViiewLib →
CONTROLLED VOCABULARY

WiiExt

An original, unofficial controlled vocabulary and thesaurus developed for Wii software cataloguing. WiiExt provides project-specific terminology used in MarcViiew's MARC 21 records.

DATA & STANDARDS

Foundations the projects build upon.

GAME DATA

GameTDB

Provides Wii game metadata used as the current primary source for MarcViiew's locally generated game database, including identifiers, titles, publishers, developers, dates, regions, genres, and synopses.

GameTDB →
BIBLIOGRAPHIC STANDARD

Library of Congress — MARC 21

MARC 21 provides the bibliographic format on which MarcViiew's catalogue and ViiewLib's record structures are based. MarcViiew's project-specific profile does not replace the official standard.

MARC 21 documentation →
INTERCHANGE FORMAT

ISO/TC 46 — ISO 2709

ISO 2709 provides the record interchange format underlying the ISO 2709 functionality implemented and tested in ViiewLib and MarcViiew.

ISO 2709 →
